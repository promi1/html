Подключение на Linux

Настройка VLESS-подключения через Happ или терминал на Linux

🍏 iOS 🤖 Android 💻 Windows 🍎 macOS 🐧 Linux

Установите Happ

Загрузите AppImage или deb-пакет Happ с официальной страницы релизов. Для AppImage: сделайте файл исполняемым (chmod +x) и запустите.

Скачать Happ (GitHub)

Скопируйте ключ подписки

В Telegram-боте нажмите на ключ подписки. Он скопируется автоматически. Ключ выглядит как ссылка на подписку (subscription URL). Если используете Telegram в браузере — выделите ссылку вручную и скопируйте (Ctrl+C).

Импортируйте конфигурацию

Вставьте ключ подписки в поле ввода Happ и нажмите Поехали. Приложение загрузит серверы из подписки автоматически.

Запустите подключение

Выберите локацию из списка и нажмите кнопку подключения. Система может запросить пароль root для создания tun-интерфейса.

Готово!

Трафик вашей системы проходит через зашифрованный VPN-туннель.

Для продвинутых: Если вы предпочитаете терминал, можно использовать Xray-core напрямую. Создайте config.json с параметрами из ключа и запустите: xray run -c config.json. Затем настройте системный прокси на socks5://127.0.0.1:10808.
