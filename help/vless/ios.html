Подключение на iPhone / iPad

Настройка VLESS-подключения через приложение Happ на iOS

🍏 iOS 🤖 Android 💻 Windows 🍎 macOS 🐧 Linux

Скачайте приложение Happ

Откройте App Store и найдите приложение Happ, либо перейдите по прямой ссылке.

Открыть в App Store

Скопируйте ключ подписки

Перейдите в Telegram-бот и нажмите на ваш ключ подписки — он автоматически скопируется в буфер обмена. Ключ выглядит как ссылка на подписку (subscription URL).

Импортируйте конфигурацию

Откройте Happ, нажмите кнопку + в правом верхнем углу, затем выберите Добавить подписку из буфера обмена. Серверы из подписки добавятся автоматически.

Подключитесь

Выберите добавленную локацию из списка серверов и нажмите большую кнопку подключения. При первом запуске iOS запросит разрешение на VPN — нажмите Разрешить.

Готово!

Ваше соединение защищено. Весь трафик теперь идёт через зашифрованный канал.

Альтернатива: Вместо Happ можно использовать Streisand — бесплатное приложение с поддержкой VLESS. Импорт конфигурации аналогичный.
