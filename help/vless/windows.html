Подключение на Windows

Настройка VLESS-подключения через приложение Happ на Windows

🍏 iOS 🤖 Android 💻 Windows 🍎 macOS 🐧 Linux

Скачайте Happ для Windows

Загрузите установочный файл с официального сайта и запустите установку. Приложение не требует дополнительных настроек при установке.

Скачать Happ (GitHub)

Скопируйте ключ подписки

Перейдите в Telegram-бот, откройте раздел с подпиской и нажмите на ваш ключ доступа. Ключ скопируется в буфер обмена. Это ссылка на подписку (subscription URL).

Вставьте конфигурацию

Откройте Happ, в главном окне вставьте скопированный ключ подписки в поле ввода и нажмите Поехали. Программа автоматически загрузит серверы из подписки.

Подключитесь к серверу

Выберите сервер из списка локаций и нажмите кнопку подключения. Windows может запросить разрешение на сетевой доступ — разрешите его.

Готово!

VPN-туннель установлен. Весь трафик вашего компьютера теперь проходит через защищённый канал.

Альтернатива: Для Windows также подходит v2rayN — популярный клиент с графическим интерфейсом. Импортируйте ключ через меню: Серверы → Импорт из буфера.
